# Matter Labs (ZKsync)

> Matter Labs is the company behind ZKsync, a family of zero-knowledge (ZK) rollup Layer 2 scaling solutions for Ethereum. ZKsync Era is an EVM-compatible ZK rollup exposing a public Ethereum-compatible JSON-RPC API (eth_* namespace) extended with ZKsync-specific methods (zks_* namespace) for batches, L1<->L2 bridging, fee estimation and proofs. This llms.txt was generated by the API Evangelist enrichment pipeline from the public developer surface (docs.zksync.io) and package registries; it is not a provider-published file.

## APIs
- [ZKsync Era JSON-RPC API](https://docs.zksync.io/zksync-protocol/api): Ethereum-compatible JSON-RPC 2.0 over HTTPS POST / WebSocket. Mainnet: https://mainnet.era.zksync.dev (chain id 324). Sepolia testnet: https://sepolia.era.zksync.dev (chain id 300).
- [Ethereum RPC namespace](https://docs.zksync.io/zksync-protocol/api/ethereum-rpc): Standard eth_* methods.
- [ZKsync (zks) RPC namespace](https://docs.zksync.io/zksync-protocol/api/zks-rpc): zks_estimateFee, zks_getBlockDetails, zks_getTransactionDetails, zks_getBridgeContracts, zks_getL1BatchDetails, zks_getConfirmedTokens, and more.
- [Debug RPC namespace](https://docs.zksync.io/zksync-protocol/api/debug-rpc): tracing methods.
- [Pub/Sub RPC (WebSocket)](https://docs.zksync.io/zksync-protocol/api/pub-sub-rpc): eth_subscribe / eth_unsubscribe (newHeads, logs, newPendingTransactions).
- [API conventions](https://docs.zksync.io/zksync-protocol/api/conventions): JSON-RPC 2.0 envelope, hex encoding (EIP-1474), batch requests.
